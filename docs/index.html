雨天・休館日の代替
  • Day 1：遊覧船が荒天欠航なら、瑞巌寺・五大堂は屋根と屋内が多いのでそのまま実行可。雨なら松島さかな市場（屋内）へ。
  • Day 2：全面雨なら仙台うみの杜水族館＋仙台駅ビルで完結。この日は車をほぼ使わずに1日成立するように組んである。

隠れた負担（該当あり）
  • 初日4時間・最終日4時間の運転が実質1人にかかる。休憩を削ると連続3時間の上限を超えるので、上の休憩は省略不可。
  • 瑞巌寺の15:00最終受付が初日の全てを規定する。昼食が30分延びると入れない。遅れたら瑞巌寺を2日目午前に回すこと。
  • 瑞鳳殿の石段は妊娠中には薦めない。水族館への振り替えを既定案としている。
  • 冬の遊覧船は体が冷える。妊娠中は冷えを避けたいので、寒がるようなら乗らない判断も正解。
  • 2泊目の仙台市内ホテルは「駐車場無料」の前提を外している（1,200〜2,000円/泊の有料）。駅徒歩圏でこの条件を満たす宿はほぼ無いための意図的な例外。無料を優先するなら郊外ホテル＋車で夕食に切り替えるが、その場合夜の運転が発生するので薦めない。
  • 光のページェントは2026年の日程が本稿時点で未発表。行けなくても旅程が成立するよう「任意」扱いにしてある。

共通の確認事項

before booking
予約時に必ず伝えること
  • 妊娠中である旨。刺身・生ものを加熱料理へ変更できるか。多くの旅館は事前連絡で対応する。
  • 貝・海老・甲殻類が食べられない人がいる旨。会席の献立には高確率で入っている。
  • 駐車場から客室までの動線。「駐車場無料」でも階段しかない宿がある。
  • 年末年始のチェックイン最終時刻と夕食開始時刻。
予算の使い道について
  • 総額118,400円前後で、20万円の予算に8万円ほどが余ります。
  • 余剰を訪問数に使うのは薦めません。1日4件の上限に既に近く、増やすと負担側が壊れます。
  • 使うなら宿です。1泊25,000円を40,000円に上げても総額14万円台。露天風呂付き客室にすれば、移動を減らしたぶんの時間が宿で回収できます。
