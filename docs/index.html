何を変えたか

the restructure
やめたこと
  • 宿の移動をやめた。松島泊→仙台泊の2箇所だったのを、松島に連泊へ。荷物の積み下ろしが3回から2回に減り、中日にチェックイン・アウトの時刻に縛られなくなります。
  • 中日の仙台往復をやめた。1時間30分の運転が20分になります。
  • 遊覧船・瑞鳳殿・水族館をやめた。冬の遊覧船は体が冷え、瑞鳳殿は石段が長い。どちらも「ゆっくり」とは逆方向でした。
残したこと
  • 牛たん。初日の昼に仙台で。松島へ向かう途中に通るので、寄り道の運転はゼロです。
  • 瑞巌寺・五大堂。中日の午前に2時間だけ。屋内・平坦で、松島に来て一度も外に出ないのも惜しいので、これだけ残しました。
  • 外出はこの2回だけです。

宿が旅の本体

the actual destination

observation：ここまで外出を削ると、旅の満足度はほぼ宿で決まります。予算20万円に対して移動と食事で使うのは3.6万円ほどなので、宿に15万円まで充てられる計算です。以下は「何を条件にするか」から先に決めた形です。

この旅で宿に求める条件
  • 客室に露天風呂か展望風呂があること。これが最優先。大浴場までの移動が要らず、混雑も気にせず、妻が自分のペースで何度でも入れます。
  • 連泊できること。2泊とも同じ部屋。荷物を出したままにできるのが妊娠中には大きい。
  • 駐車場から部屋まで階段がないこと。松島の宿は高台に多く、ここは実際に差が出ます。
  • 2食付き。夜に車を出さないための条件です。
  • 館内で時間を潰せること（ラウンジ・読書スペースなど）。こもる旅では「部屋以外の居場所」があるかどうかが効きます。
温泉について（事実関係）
  • 温泉の禁忌症にあった「妊娠中」の記載は、2014年に環境省が削除しました。医学的根拠がないというのが理由です確認済 08-16。
  • ただし削除されたのは「妊娠中だから入ってはいけない」という一般則であって、個別の注意が消えたわけではありません。のぼせ・脱水・浴室での転倒は妊娠中でなくても起きます。
  • 実務的には、長湯をしない・湯温を上げすぎない・一人で入らない・手すりのある浴室を選ぶ。客室露天を勧めているのは、この全部が自分の裁量でできるからです。
  • かかりつけ医に一度確認してください。経過によっては個別に止められることがあります。

「1室20,000円」の前提を外しています

共通条件では宿を1室20,000円としていましたが、この旅程ではそこが旅の中身そのものなので、意図的に超過させています。上表の45,000円前後（大観荘・好風亭クラス）で組むと総額は約126,000円、一の坊のオールインクルーシブ（1泊75,000円想定）にすると総額約186,000円で、20万円の予算にぎりぎり収まりますがほぼ使い切ります。どちらも予算内ではありますが、使い切ってよいかは要相談です。下の費用表は45,000円のほうで計算しています。

旅程

冬の松島は、湾が凪いで島影が硬く見える季節です。人も夏よりずっと少ない。初日に距離を使い切り、中日は宿から出ない——観光地を回るのではなく、宿に居続けるための組み方をしています。

共通の確認事項

before booking
予約時に必ず伝えること・確認すること
  • 妊娠中である旨。刺身・生ものを加熱料理へ変更できるか。多くの旅館は事前連絡で対応する。
  • 貝・海老・甲殻類が食べられない人がいる旨。会席の献立には高確率で入っている。
  • 2泊で献立が変わるか。同じ会席が2回出る宿がある。
  • 駐車場から客室までの動線。「駐車場無料」でも階段しかない宿がある。松島は高台の宿が多いので特に。
  • 客室風呂の仕様。源泉か沸かし湯か、冬に使えるか（シャッターや囲いの有無）、湯温を自分で調整できるか。
  • レイトチェックアウトの可否と、年末年始のチェックイン最終時刻・夕食開始時刻。
予算の使い道について
  • 宿以外（移動・食事・入場料）で使うのは約36,000円だけです。残りは全部宿に充てられます。
  • 45,000円/泊で総額126,300円、予算に73,700円の余裕。
  • さらに宿に寄せるなら、一の坊のオールインクルーシブ（75,000円/泊想定）で総額約186,300円。予算内だがほぼ使い切るので要相談です。
  • 逆に締めるなら、露天風呂付き客室をやめて通常客室（30,000円/泊前後）にすると総額96,000円台。ただしこの旅程の主目的が薄まります。
